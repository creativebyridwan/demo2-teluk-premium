# Demo Klinik Gigi Arab 2 — Teluk Premium (biru)

Landing page demo berbahasa Arab (RTL) untuk presentasi walk-in ke klinik
gigi di Libya. Dibangun dari nol, bukan terjemahan Folia.

- Palet: #205781 (biru tua), #4F959D (teal), #98D2C0 (mint), #F6F8D5 (krem)
- Font: Cairo (display) + Almarai (body)
- 12 section: header, hero + statistik, bar kepercayaan, grid layanan
  (implan, Hollywood Smile, veneer, Invisalign), tabel harga LYD,
  slider before/after, kartu dokter CV, alur pasien, testimoni,
  form booking, FAQ, lokasi/peta + footer

## Penting: ini DEMO, bukan situs klinik sungguhan

Semua nama, harga, angka, foto, dan testimoni di situs ini adalah contoh
(placeholder) yang wajib diganti dengan data asli klinik. Harga dalam
dinar Libya (LYD) memakai estimasi pasar, bukan harga satu klinik.
Tidak ada cicilan, tidak ada klaim asuransi, dan form booking belum
terhubung ke backend apa pun.

## File

- `index.html` — seluruh landing page
- `style.css` — semua gaya
- `main.js` — accordion FAQ, slider before/after, form booking, reveal
- `assets/` — 5 gambar (hero, 2 dokter, before/after)
